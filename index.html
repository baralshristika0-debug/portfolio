About me

I'm a fourth-semester Computer Science student specializing in Network Technology & Cybersecurity. I like the overlap between how a website is built and how it's kept safe — clean semantic markup, thoughtful layout, and an eye for what could go wrong.

Outside coursework, I'm usually deep in a CTF challenge, tinkering with a Raspberry Pi, or refining this portfolio. This project itself doubles as coursework for WBD-113 Web Designing: it demonstrates HTML5 semantics, responsive CSS, and JavaScript interaction end to end.
